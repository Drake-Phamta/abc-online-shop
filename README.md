# ABC Online Shop: from requirements to running code

Course project of Information Systems Analysis and Design (PTIT, 2026): the analysis and design models of the
ABC Online Shop in Visual Paradigm, the database and the code skeleton generated from the models, and a Java
implementation with an AI search (text, voice, photo) that follows the design class for class. Everything of the essay lives in this one folder (also the git repository).
Double-click **CHAY_DEMO.bat** to run the shop; open [showcase/index.html](showcase/index.html) for the guided tour
used at the defence.

## Run

Double-click [CHAY_DEMO.bat](CHAY_DEMO.bat): it finds Java 17 (on this machine `java` on the PATH is an older Java 8,
so the script uses `JAVA_HOME`), builds the jar if it is missing, starts the server on a fresh demo database and
opens http://localhost:8080 when the server answers. Close its window to stop the server; `CHAY_DEMO.bat keep` keeps
the data of the previous run.

The showcase can start the shop by itself. On every run CHAY_DEMO.bat registers the link type `abcshop:` for the
current Windows user ([showcase/abcshop.ps1](showcase/abcshop.ps1), no admin rights). When the showcase is opened
from this computer, "Open the shop" (green dot: running, grey dot: stopped) runs CHAY_DEMO.bat if the server does not
answer, and "Show in File Explorer" / "Open in Visual Paradigm" open a file of the project; the handler refuses any
path outside the project folder. The browser asks once per click, choose Open. To remove the link type:
`reg delete "HKCU\Software\Classes\abcshop" /f`. After a document changes, rebuild its readable page with
`python showcase/build_pages.py`.

Public copy: https://drake-phamta.github.io/abc-online-shop/ (GitHub Pages; there the shop button opens the live shop
while the tunnel below runs and otherwise explains how to run the shop, and the File Explorer buttons are hidden). After committing, `powershell -NoProfile -File
showcase/publish_pages.ps1` publishes the current state as one snapshot commit with the essay PDF; the local history,
De_bai, Luu_tru and the docx stay on this computer.

The running shop itself can be reached from the Internet: double-click [CHAY_TUNNEL.bat](CHAY_TUNNEL.bat). It starts the
shop if needed, opens a Cloudflare quick tunnel ([tools/quick_tunnel.ps1](tools/quick_tunnel.ps1), no Cloudflare
account; the official `cloudflared.exe` is downloaded once into `%LOCALAPPDATA%\cloudflared` and its signature
checked), prints the public address `https://....trycloudflare.com`, copies it and opens it. The address changes every
time and works while that window stays open (if cloudflared stops, the script starts it again); each new address is
written into the Website field of the GitHub repository (and into `live.txt` of the branch `live`, in case the GitHub
API is out of its hourly limit), so the shop button of the published showcase opens the live shop. If the shop stops
answering for 3 minutes, the script starts it again with its data kept. Anyone who has the address can use the demo accounts, so close the window after the defence.

By hand (JDK 17, Maven 3.9; Python 3.10+ and Node 18+ with Microsoft Edge for the tests):

```
cd app
mvn -q package -DskipTests
"%JAVA_HOME%\bin\java" -jar target/abc-online-shop-1.0.0.jar --abc.db.reset=true
```

The folder name has Vietnamese letters; `app/.mvn/jvm.config` starts Maven with UTF-8, without it Maven stops with
"Input length = 1". `--abc.db.reset=true` recreates the SQLite file `app/data/abc_shop.db` from the DDL and
the seed data; without it the existing file is kept. Accounts (password `demo1234`): `an.nguyen@example.com` (VIP
customer), `lan.tran@example.com` (new customer), `sales@example.com` (order board), `warehouse@example.com`
(inventory). Test cards: `4242 4242 4242 4242` is approved, a number ending in `0002` is declined. Alt+L shows the
design lens (view, endpoint, controller, service, DAO and tables of every part of a screen).

## Test

```
cd app && mvn test                       # 24 JUnit tests (model rules, checkout flow, AI search on a real SQLite file)
python tests/smoke_api.py                # 36 checks over HTTP (server running)
cd tests/e2e && npm install && node run_e2e.mjs   # 30 checks in Edge on a fresh database, screenshots
python tests/design_vs_code.py           # VP design model against the compiled code (run mvn compile first)
python tests/vpgen_vs_code.py            # code generated by VP Instant Generator against the compiled code
python tests/search_eval.py              # AI search against keyword search: 30 queries, 84 photos (server running)
python db/compare_schema.py              # VP DDL and the VP-generated database against db/schema.sql
python tests/check_links.py              # every link of the documents and the showcase opens a file
```
