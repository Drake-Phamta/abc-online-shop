TRACEABILITY: requirement → use case → analysis → design → database → code → test

Every link below opens the artefact (diagram image, specification section, source line or test). Diagram codes are the names of the diagrams in the VP project vp/ABC_Online_Shop_V4.vpp; the images in vp/png/ are captured from the VP canvas. Line numbers are those of the current commit; tests/design_vs_code.py checks that the design classes and the calls of the design sequences exist in the code, so the middle of each chain cannot drift.
